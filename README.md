> Interactive Command Line Interface (CLI) tool for crafting standard Conventional Commits (`feat:`, `fix:`, `docs:`, etc.) and automated changelogs.

---

## 🚀 Quick Start

### 1. Usage
```bash
npx git-commit-craft-cli feat "add user profile API endpoint" auth
```
Output:
```
feat(auth): add user profile API endpoint
```

### 2. Run Test Suite
```bash
npm test
```
